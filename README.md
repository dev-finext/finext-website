# Finext — Wireframe (שלב 1)

מבנה האתר החדש של Finext, בנוי על המבנה של waracle.com. אפור בלבד, בלי תמונות, עברית RTL, רספונסיבי.

## איך פותחים
פותחים את `index.html` בדפדפן. אין build ואין שרת. `wireframe-map.html` מראה את כל העמודים, את ההתאמה ל-Waracle ואת העמודים שלא נבנו.

## למעצב
| מה | איפה |
|---|---|
| צבעים, פונטים, גדלי כותרות, מרווחים | `assets/css/tokens.css` (קובץ אחד, כל האתר מושפע ממנו) |
| תמונות | כל משבצת אפורה עם X (`div.ph`). הטקסט עליה הוא היחס והרמז. מחליפים ב-`<img>` או ברקע. רקעי hero הם `.ph--bg` |
| רכיבים | `assets/css/wireframe.css` |
| התנהגויות (תפריט, קרוסלות, אקורדיון, טפסים) | `assets/js/wireframe.js` |
| הערות wireframe | הכפתור הצף `NOTES` מדליק/מכבה תוויות רכיב ותגיות ״דוגמה״. לפני פרודקשן מוחקים את הבלוק "WIREFRAME-ONLY LAYER" ב-CSS ואת `.wf-tools` |

## תוכן
`CONTENT-REPORT.md` מפרט מה הגיע מהחומרים שנמסרו, מה הומצא ומה לא נכנס. כל תוכן שהומצא מסומן בתג ״דוגמה״ בתוך העמוד.

## `_build/`
מחולל Python שיוצר את קבצי ה-HTML (header/footer וכרטיסים מוגדרים פעם אחת). `python _build/build.py` **דורס** את כל ה-HTML בשורש. אחרי שהמעצב מתחיל לערוך את ה-HTML ישירות, לא מריצים אותו.
